# Claim review record

Copy one record per atomic claim. This is a manual template, not a validator.
Review with model identity hidden and retain the original report wording.

- Case ID / submission ID / claim ID:
- Blinded model label / submission rank:
- Exact report excerpt and qualifications:
- Atomic claim and scope (sequence fact, relationship or interpretation):
- Sequence IDs, coordinate convention, strand, units and input SHA-256:
- Submitted code and cited output paths / hashes:
- Submission frozen at:

## Checks and evidence

- Submitted-code reproduction: result and artifact:
- Independent checker or reference: method, version, result and artifact:
- Background assumptions, competing explanations and completed controls:
- Exploration/search history relevant to selection:
- Confirmation plan frozen at / code hash:
- Withheld-data provenance and split groups / checksum:
- Predicted result, test, exclusions and multiple-test family/procedure:
- Confirmation outcome, effect size, uncertainty and limitations:
- Biological interpretation: experimental/computational support, source and
  organism/condition; additional evidence needed:
- Prior-art review: queries, databases, versions, dates and relevant links:

Use “not applicable” for checks that the claim does not require, with a reason.
Keep proposed follow-up separate from completed checks.

## Verdict

- Observation/interpretation: verified / refuted / unresolved:
- Scope and evidence supporting that verdict:
- Novelty: already known / candidate contribution after review / unresolved:
- Limitations and remaining confirmation:
- Reviewer and date / second review and disagreements:

Attach the evidence rather than relying on reviewer or model confidence.
See the [verification procedure](verification.md) for the meaning of each status.
